# 🚑 RapidRescue - Smart Emergency Route Assistant

RapidRescue is a full-stack MERN application designed to assist users during emergencies by locating nearby emergency services, generating optimal routes, managing emergency contacts, and sending SOS alerts with location details.

## ✨ Features

### 🔐 Authentication

* User Registration & Login
* JWT Authentication
* Protected Routes
* User Profile Management

### 🚨 Emergency Assistance

* Medical Emergency
* Police Assistance
* Fire Emergency
* Fuel Station Finder
* Vehicle Breakdown Assistance
* Pharmacy Search

### 📍 Navigation & Routing

* Live Location Detection
* Manual Location Search
* Nearby Emergency Service Discovery
* Interactive Maps using Leaflet & OpenStreetMap
* Shortest Route Generation using OSRM

### 🚗 Multi-Stop Route Optimization

* Select Multiple Emergency Destinations
* Dijkstra Algorithm Based Optimization
* Optimized Emergency Journey Planning
* Distance and ETA Calculation

### 📱 SOS System

* Emergency Contact Management
* WhatsApp SOS Integration
* Live Location Sharing
* SOS Alert History

### 📊 History Tracking

* Emergency Search History
* SOS Alert History
* Multi-Stop Route History

## 🧠 Algorithms Used

### Dijkstra Algorithm

Used for:

* Finding nearest emergency services
* Multi-stop route optimization
* Emergency route planning

### OSRM Routing Engine

Used for:

* Route generation
* Distance calculation
* ETA estimation
* Route visualization

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
cd RapidRescue
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
